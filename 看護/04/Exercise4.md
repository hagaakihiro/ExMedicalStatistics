# 独立性を調べる$\chi^2$検定

<u>好きか嫌いか、などのような２つもしくはそれ以上の質的変数が独立かどうかを調べるために利用する検定。</u>

例題3：治療Aと治療Bの効果を調べたところ、次のような結果が得られた。

|  | A | B | C |
| --- | --- | --- | --- |
| 有効（P） | 10 | 27 | 37 |
| 無効（N） | 10 | 13 | 23 |
| 計 | 20 | 40 | 60 |

治療Aと治療Bに差があると言えるか？

（手順）

帰無仮説$H_0$：治療Aと治療Bは独立、すなわち差がない（対立仮説$H_1$：治療Aと治療Bに関連あり、すなわち差がある）

検定統計量：$\chi^2$値。$\chi^2=\sum_i (O_i-E_i)^2/E_i$で、$O_i$は観測値、$E_i$は期待値。自由度は1。

有意水準：上側5%とする

なお、期待値は次のようになる：

|  | A | B | C |
| --- | --- | --- | --- |
| 有効（P） | $37*20/60 = 12.33$ | $37*40/60 = 24.67$ | 37 |
| 無効（N） | $23*20/60 = 7.67$ | $23*40/60 = 15.33$ | 23 |
| 計 | 20 | 40 | 60 |

$\chi^2= (10-12.33)^2/12.33 + (27-24.67)^2/24.67 + (10-7.67)^2/7.67 + (13-15.33)^2/15.33 = 1.73$

```r
> pchisq(1.73,1, lower.tail=FALSE)
```

＿＿＿＿

$p$値が＿＿＿＿であるので、統計検定量は有意水準＿＿＿＿であり、
帰無仮説は＿＿＿＿。

$\chi^2$の検定にも、chisq.test関数が用意されている：

```r
> cross <- matrix(c(10,10,27,13),2,2)
> rownames(cross) <- c("P","N")
> colnames(cross) <- c("A","B")
> cross
> chisq.test(cross,correct=FALSE)
```

上と同じ結果が与えられていることを確認できたでしょうか？
なお、上と同じ結果を得る目的でここではcorrect=FALSEというオプションを入れています。
このオプションを外した結果も出してみましょう。実はこちらの方がより正確です。
というのも、$\chi^2$分布は連続分布なので、実際のデータが頻度なので整数ですが、これを連続性に近似するための補正を加えているからです。
また、分割表に対する独立性の検定に関しては、フィッシャーの正確確率検定というものもあります。
フィッシャーの正確確率検定は、分割表が得られる場合の数を全て計算して得られる結果であるため、$\chi^2$検定よりも正確ということも覚えておきましょう。

```r
> fisher.test(cross)
```

とするとフィッシャーの正確確率検定が行われます。$\chi^2$検定との比較を行ってみてください。

# 適合性を調べる$\chi^2$検定

<u>期待される度数と実測された度数が適合しているかどうかを調べるために利用する検定。</u>

例題4：メンデルは556個のえんどう豆を標本にとって、その色と形を同時に調べて次の結果を得た。

| 円形の黄色のえんどう豆 | 315 |
| --- | --- |
| 円形の緑色のえんどう豆 | 108 |
| 尖った黄色のえんどう豆 | 101 |
| 尖った緑色のえんどう豆 | 32 |

この割合がメンデルの法則$9:3:3:1$に従っていると言えるでしょうか？

（手順）

帰無仮説$H_0$：観測値はメンデルの法則に適合している（対立仮説$H_1$：メンデルの法則に適合していない）

検定統計量：$\chi^2$値。$\chi^2=\sum_i (O_i-E_i)^2/E_i$で、$O_i$は観測値、$E_i$は期待値。自由度は4-1=3。

有意水準：上側5%とする

期待値は次の通りである。

| 円形の黄色のえんどう豆 | $556 \times 9/16 = 312.75$ |
| --- | --- |
| 円形の緑色のえんどう豆 | $556 \times 3/16 = 104.25$ |
| 尖った黄色のえんどう豆 | $556 \times 3/16 = 104.25$ |
| 尖った緑色のえんどう豆 | $556 \times 1/16 = 34.75$ |

$\chi^2= (315-312.75)^2/312.75 + (108-104.25)^2/104.25 + (101-104.25)^2/104.25 + (32-34.75)^2/34.75 = 0.47$

```r
> pchisq(0.47, 3, lower.tail=FALSE)
```

＿＿＿＿

$p$値が＿＿＿＿であるので、統計検定量は有意水準＿＿＿＿であり、
帰無仮説は＿＿＿＿。

適合性の検定にも、chisq.test関数が使える：

```r
> data = c(315,108,101,32)
> prob = c(9/16,3/16,3/16,1/16)
> chisq.test(data,p=prob)
```

# 用語についての補足

第1種の誤り（過誤）$\cdots$ 帰無仮説が実際には真であるのに棄却してしまう過誤（偽陽性）

第2種の誤り（過誤）$\cdots$ 対立仮説が実際には真であるのに帰無仮説を採用してしまう過誤（偽陰性）

有意水準$\cdots$ 帰無仮説のもとで、棄却域に入る検定統計量が発生する確率（パーセント）のことで、5%や1%がよく使われる
（物理学の世界では$3 \sigma (\sim0.13%)$でEvidenceレベル、$5 \sigma (\sim0.00003%)$でDiscoveryレベル、数学の世界では証明されなければ、どんなに確率が低い事象があったとしても無意味と言われているように、分野によって有意水準の値や考え方は異なる）。

$p$値$\cdots$ 統計的仮説検定において、帰無仮説のもとで、観測された検定統計量以上に極端な値が出る確率のこと。$p$値が小さいほど、観測された結果は帰無仮説のもとでは起こりにくいことを意味する。
